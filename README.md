# 👴⚖️ Neto

> **Uma Justiça que entende as pessoas e que pode ser entendida por elas.**

**Macrodesafio 3 – Entenderam Né**

> ⚠️ **Este repositório contém o protótipo de um chatbot de WhatsApp.** A solução final prevê um canal oficial do TJPE no WhatsApp e um site do chatbot Neto; esta versão serve para demonstrar a proposta, o fluxo de conversa e a experiência de uso.

---

## 📖 Sobre o projeto

O Neto é um assistente virtual do Judiciário voltado à orientação de pessoas idosas, especialmente na prevenção de golpes e no atendimento após a ocorrência dessas situações.

A ferramenta ajuda a identificar possíveis tentativas de fraude e orienta sobre as medidas de segurança que podem ser adotadas para minimizar os danos, sempre em linguagem simples, acessível e acolhedora.

## 🎯 Objetivos

- Orientar pessoas idosas sobre como prevenir golpes.
- Ajudar a identificar tentativas de fraude (mensagens, ligações, links e pedidos suspeitos).
- Indicar o que fazer imediatamente após cair em um golpe, para reduzir prejuízos.
- Aproximar o Judiciário da população por meio de uma comunicação simples e sem juridiquês.
- Utilizar um canal que o público já conhece e utiliza no dia a dia: o WhatsApp.

## 👥 Público-alvo

Pessoas idosas, seus familiares e cuidadores que precisam de orientação rápida e confiável sobre golpes e fraudes.

## ✨ Funcionalidades do protótipo

- 🔎 Orientações para identificar possíveis golpes.
- 🛡️ Dicas de segurança e prevenção.
- 🚨 Passo a passo de o que fazer após ser vítima de um golpe.
- 🗣️ Identificador de mensagens de golpe.

## 🚀 Como executar localmente

**Pré-requisitos:** [Node.js](https://nodejs.org/) (versão 18 ou superior) e npm instalados.

```bash
# 1. Clone o repositório
git clone https://github.com/geovannathereza/Neto-IA-CRIEJAM-2026

# 2. Acesse a pasta do projeto
cd Neto-IA-CRIEJAM-2026

# 3. Instale as dependências
npm install -g bun
bun install

# 4. Inicie o localhost
bun run dev

```

Depois, acesse o endereço exibido no terminal (normalmente `http://localhost:8080/`).
